# Gestor LDS - Nuevo Trujillo

![Version](https://img.shields.io/badge/version-1.7.1-blue) ![Flutter](https://img.shields.io/badge/Flutter-3.0-02569B) ![Status](https://img.shields.io/badge/status-En_Desarrollo-orange)

**Gestor LDS** es una aplicación móvil desarrollada para optimizar la gestión de reuniones, agendas y la organización del Barrio Nuevo Trujillo de La Iglesia de Jesucristo de los Santos de los Últimos Días.

Desarrollado con ❤️ por **ATHEM DevWorks**.

## Características Principales

* 📅 **Agenda de Reuniones:** Gestión de entrevistas y reuniones dominicales.
* 👥 **Directorio Local:** Acceso rápido a contactos de líderes (seguro y privado).
* 🔔 **Notificaciones:** Recordatorios para asignaciones y eventos.
* 🚀 **Acceso Directo:** Integración con herramientas oficiales mediante `url_launcher`.
* 🎨 **Interfaz Personalizada:** Diseño limpio y fácil de usar.

## Tecnologías

* **Framework:** Flutter & Dart
* **Gestor de Estado:** Provider
* **Backend/Servicios:** Firebase Core
* **Utilidades:** Intl (Fechas), URL Launcher, Share Plus.

## Instalación y Configuración

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/nuevotrujilloward/gestor_lds.git](https://github.com/nuevotrujilloward/gestor_lds.git)
    ```

2.  **Instalar dependencias:**
    ```bash
    flutter pub get
    ```

3.  **Generar Assets (Iconos y Splash):**
    ```bash
    dart run flutter_native_splash:create
    dart run flutter_launcher_icons
    ```

4.  **Ejecutar:**
    ```bash
    flutter run
    ```
